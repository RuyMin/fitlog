  - 서버는 이전에 올린 파일인지(`previous_archive_id`) 알려 주지만, 화면에는 표시하지 않습니다.

- [ ] **큰 파일 분석 시간 초과**
  - `max_tokens` 32000에 클라이언트 타임아웃은 90초(재시도 1회)여서, 행이 많으면 실패할 가능성이 큽니다. 실패해도 하루 AI 한도는 1회 차감됩니다.
  - v1.1.0에서는 설정 화면에 경고 문구만 추가했습니다.
  - 후보: 스트리밍 호출, 시트를 나눠 여러 번 호출, 실패 시 한도 차감 취소.

## AI 기록

- [ ] **브랜드 메뉴의 공식 영양 정보를 웹에서 찾기**
  - 지금은 AI 호출에 웹 검색이 없어, 브랜드 메뉴(예: 죠샌드위치 치킨샐러드)도 사진·설명 기반 추정값만 들어갑니다.
  - 안: Anthropic 웹 검색 도구(Haiku는 `web_search_20250305`)를 요청에 추가합니다. 브랜드·매장명이 있을 때만 검색하고 요청당 최대 2회로 제한합니다. 찾으면 "공식 정보" 표시와 출처 주소를 메모에 남기고, 못 찾으면 지금처럼 추정합니다.
  - 정할 것: 자동 검색과 입력창 체크("웹에서 공식 정보 찾기") 중 어느 방식으로 할지.
  - 필요한 준비:
    - Anthropic 콘솔에서 조직의 웹 검색 허용을 켜야 합니다.
    - 검색어가 검색 서비스로 전달되므로 AI 전송 고지를 바꾸고(`ai_transfer` 버전 변경) 전원에게 다시 동의를 받아야 합니다.
    - 구조화 출력과 웹 검색을 함께 쓸 수 있는지 실제 키로 시험해야 합니다.
  - 비용: 검색 1회 약 $0.01과 검색 결과 토큰. 초안 생성 시간이 5~15초 늘어납니다.
