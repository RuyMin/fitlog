# 해야 할 일 (backlog)

정리되지 않은 아이디어나 미뤄 둔 수정 사항을 적어 둡니다. 작업을 시작할 때 이슈나 PR로 옮깁니다.

## 알림과 AI 코칭 (2026-10-31 정리, 코드 정리 다음 순서)

실사용자 4명 중 3명이 써 봤지만 며칠 뒤 앱을 여는 것 자체를 잊었습니다. 알림이 없는 것이 가장 큰 이유로 보입니다.

- [ ] **1단계: 웹 푸시 알림**
  - 안드로이드 크롬, 홈 화면에 추가한 아이폰(iOS 16.4+)에서 됩니다. 네이티브 앱 없이 지금 웹앱에 붙입니다.
  - 하루 1~2번만 보냅니다. 예: 아침 체중, 저녁 운동 기록. 홈 "다음 할 일" 규칙을 써서 이미 한 일은 알리지 않습니다.
  - 설정에서 켜기·끄기와 시간을 고릅니다.
  - 필요한 것: VAPID 키, 서비스 워커 `push` 처리, 구독 저장 테이블, 정해진 시각에 보내는 작업.
  - 확인할 것: 알림이 있으면 2주 뒤에도 돌아오는가.
- [ ] **2단계: 주간 코칭 한마디**
  - 일요일 밤 한 번, 이번 주 정리와 다음 주 제안을 AI가 한 번 호출로 만들어 알림으로 보냅니다.
  - 확인할 것: 코칭을 원하는가, 사용자당 AI 비용은 얼마인가.
- [ ] **3단계: 대화형 코칭**
  - 기록과 질문을 대화창 하나로 합칩니다. 기록은 지금처럼 초안 카드 → 확인 → 저장으로 빠르게 합니다.
  - AI에 도구를 줍니다: 기록 초안 만들기, 오늘 요약, 통계 보기.
  - 비용: 대화 길이 제한, 오래된 대화 요약, 프롬프트 캐시가 필요합니다.
- **2·3단계 공통 준비**
  - 기록 자체를 AI에 보내야 하므로 AI 전송 고지를 바꾸고(`ai_transfer` 버전 변경) 다시 동의를 받아야 합니다.
  - 건강 조언의 선: 운동·식습관 코칭까지만 합니다. 질병·약·진단은 전문가 상담으로 안내하고, 극단적인 감량·식단 요청은 말립니다.
  - 대화를 저장할지, 저장한다면 보관 기간과 삭제 방법을 정해야 합니다.

## Excel AI 가져오기

- [ ] **같은 파일을 다시 올리면 중복 저장될 수 있음**
  - AI 미리보기는 매번 임의의 식별자(`ai_<hex>_<n>`)를 붙여서, 같은 파일을 다시 올리면 모두 "신규"로 비교됩니다.
  - 서버는 이전에 올린 파일인지(`previous_archive_id`) 알려 주지만, 화면에는 표시하지 않습니다.
  - 해결 방향은 아직 정리 중입니다.
- [ ] **큰 파일 분석 시간 초과**
  - `max_tokens` 32000에 클라이언트 타임아웃은 90초(재시도 1회)여서, 행이 많으면 실패할 가능성이 큽니다. 실패해도 하루 AI 한도는 1회 차감됩니다.
  - v1.1.0에서는 설정 화면에 경고 문구만 추가했습니다.
  - 후보: 스트리밍 호출, 시트를 나눠 여러 번 호출, 실패 시 한도 차감 취소.

## AI 기록

- [ ] **브랜드 메뉴의 공식 영양 정보를 웹에서 찾기**
  - 지금은 AI 호출에 웹 검색이 없어, 브랜드 메뉴(예: 죠샌드위치 치킨샐러드)도 사진·설명 기반 추정값만 들어갑니다.
  - 안: Anthropic 웹 검색 도구(Haiku는 `web_search_20250305`)를 요청에 추가합니다. 브랜드·매장명이 있을 때만 검색하고 요청당 최대 2회로 제한합니다. 찾으면 "공식 정보" 표시와 출처 주소를 메모에 남기고, 못 찾으면 지금처럼 추정합니다.
  - 정할 것: 자동 검색과 입력창 체크("웹에서 공식 정보 찾기") 중 어느 방식으로 할지.
  - 필요한 준비:
    - Anthropic 콘솔에서 조직의 웹 검색 허용을 켜야 합니다.
    - 검색어가 검색 서비스로 전달되므로 AI 전송 고지를 바꾸고(`ai_transfer` 버전 변경) 전원에게 다시 동의를 받아야 합니다.
    - 구조화 출력과 웹 검색을 함께 쓸 수 있는지 실제 키로 시험해야 합니다.
  - 비용: 검색 1회 약 $0.01과 검색 결과 토큰. 초안 생성 시간이 5~15초 늘어납니다.
