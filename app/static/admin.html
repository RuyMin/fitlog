기본 종목

모든 사용자가 운동을 추가할 때 고르는 목록이에요. 바꾸면 모두에게 바로 반영되고, 이미 쓰고 있는 사용자의 종목 이름과 기록은 바뀌지 않아요. 사용자가 직접 만든 종목은 그 사람에게만 보이고 여기에는 나오지 않아요.

멤버 초대

링크를 받은 사람이 Google 계정으로 가입하면 멤버가 됩니다. 멤버의 기록은 그 사람에게만 보이고, 관리자도 볼 수 없어요.

지금만 보여요. 서버는 링크를 다시 보여 주지 않으니 바로 전달해 주세요. 한 번만 쓸 수 있고, 링크를 가진 사람은 누구든 가입할 수 있어요. 메신저 개인 대화처럼 받을 사람에게만 보내 주세요.

최근 초대

AI 공용 키

등록된 키
확인 중

모든 사용자의 요청이 이 키로 호출되고, 요금은 이 키의 Anthropic 계정에 청구됩니다. 키는 서버에 암호화해 저장하며 다시 화면에 보여 주지 않습니다. 저장할 때 키가 동작하는지만 확인하며, 이때 기록 데이터는 보내지 않습니다. 새 키를 저장하면 기존 키를 대체합니다. 키는 Anthropic 콘솔(console.anthropic.com)의 API Keys 메뉴에서 만들고, 크레딧(결제) 등록이 필요합니다.

속도 통계

휴대폰에서 기다린 시간(체감)과 그중 서버 처리 시간을 나눠 보여 줍니다. 둘의 차이는 네트워크(Funnel) 구간이에요. 숫자는 보통(중앙값) / 느릴 때(상위 10%)이고, 기록은 14일 보관합니다.
