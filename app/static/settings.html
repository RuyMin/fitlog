선택 입력이에요. 성별·출생연도·키는 목표 계산에만 쓰고, 다른 기록처럼 이 계정에만 보이며 운영자 NAS에 저장됩니다. 입력하지 않으면 기본 목표를 쓰고, 아래 ‘입력한 목표 정보 지우기’로 언제든 지울 수 있어요.

AI 외부 전송 고지 (선택 동의, 버전 2026-10-21)
  • 받는 곳: Anthropic(미국). 국외로 전송됩니다.
  • 전송 항목: AI 기능을 사용할 때 입력한 문장과 첨부한 사진(음식·영양성분표 등), 현재 시각·시간대, 본인의 운동 종목 이름. 기록 초안을 만드는 데에만 씁니다. 사진은 FitLog에 저장하지 않으며, 보내기 전에 휴대폰에서 위치 정보 등 사진 정보를 지웁니다.
  • 조건: 운영자의 Anthropic API 계정(공용 키)으로 호출하며 비용은 운영자가 부담합니다. 해당 데이터에는 운영자와 Anthropic 사이의 API 약관이 적용되고, 운영자는 키 계정의 사용량 기록에서 호출 횟수·사용량을 볼 수 있습니다. 보관·학습 정책은 Anthropic의 공식 문서를 확인해 주세요. 사람마다 하루 사용 횟수에 제한이 있습니다.
  • 철회: 언제든 철회할 수 있으며, 철회하면 전송이 즉시 중단됩니다. 동의하지 않아도 기록 기능은 모두 사용할 수 있습니다.

서비스 이용 동의를 철회하거나 모든 기록을 삭제하려면 운영자에게 요청해 주세요. 삭제 전에 만든 백업 파일에는 백업 보관 기간 동안 남습니다.

속도 개선을 위해 앱이 서버에 보낸 요청의 시각·종류·걸린 시간만 14일 동안 기록합니다. 운동·식단 등 기록 내용은 남기지 않습니다.

화면을 빨리 띄우려고 홈·운동·식단·몸 화면의 최근 데이터를 이 기기에만 최대 7일 보관했다가 먼저 보여줍니다. 로그아웃하거나 다른 계정으로 로그인하면 지웁니다.

AI 기록 도우미

홈 화면의 "문장으로 기록하기"는 운영자가 등록한 공용 Anthropic API 키로 동작하며, 비용은 운영자가 부담합니다. 사람마다 하루 사용 횟수에 제한이 있습니다. 사용하려면 위 계정 카드에서 "AI 외부 전송"에 동의해 주세요.

멤버 초대

관리자에게만 보여요. 링크를 받은 사람이 Google 계정으로 가입하면 멤버가 됩니다. 멤버의 기록은 그 사람에게만 보이고, 관리자도 볼 수 없어요.

지금만 보여요. 서버는 링크를 다시 보여 주지 않으니 바로 전달해 주세요. 한 번만 쓸 수 있고, 링크를 가진 사람은 누구든 가입할 수 있어요. 메신저 개인 대화처럼 받을 사람에게만 보내 주세요.
